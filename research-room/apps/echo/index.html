Mathematical convention

Normalized circular basis used throughout the explorer

This fixes the state vector, RF operator, Fourier signs, gradient shifts, and signal scaling used in every lesson.

Cartesian → circular channelsC₊ = (Mx + iMy)/√2 C₋ = (Mx − iMy)/√2 q = [C₊, C₋, Mz]ᵀ = S M
Basis matricesS = (1/√2)[ 1 i 0 1 −i 0 0 0 √2 ] S⁻¹ = Sᴴ
RF propagationRch = S R S⁻¹ Qout[n] = Rch Qin[n]

Rows are output channels; columns are input channels.

Fourier/order conventionq(z) = Σₙ Q[n] exp(+i2πnz/L) Q[n] = (1/L)∫q(z) exp(−i2πnz/L) dz

A positive C₊ phase ramp shifts Fₙ⁺ toward larger n; C₋ shifts oppositely.
